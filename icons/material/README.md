# Google Material Symbols

These unmodified 24 px SVGs are from Google's Material Symbols Rounded set.

- Source: https://github.com/google/material-design-icons/tree/master/symbols/web
- Copyright Google LLC. Distributed under the Apache License 2.0; see LICENSE.
- Icons: close, expand_more, chevron_right, arrow_forward, drag_indicator, add, check_circle, cancel.

The extension loads these SVGs locally as CSS masks. No icon font, CDN, or runtime network request is used. Accessible button labels are translated by the interface.
